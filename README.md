# 🎯 AKS Quiz Website

Welcome to **AKS Quiz**! 🧠✨

A fun and interactive online quiz website where students can enter their details, verify with OTP, answer questions, and see their final score.

## 🌟 Features

- 👤 Student details form
- 🔐 OTP verification
- 🧠 Multiple-choice quiz
- ⏱️ Quiz timer
- 📊 Progress bar
- ✅ Correct answer tracking
- ❌ Wrong answer tracking
- 🏆 Final score
- 📈 Percentage result
- 🔄 Try Again option
- 🎨 Attractive animated design
- 📱 Mobile-friendly layout

## 🚀 How to Use

1. Enter your name.
2. Select your class.
3. Select your subject.
4. Enter your mobile number.
5. Click **Send OTP**.
6. Enter the OTP.
7. Start the quiz.
8. Answer all questions.
9. See your final score.

## 🔐 OTP Note

The current version uses a **demo OTP system**.

For real SMS OTP verification, a backend or authentication service such as Firebase Phone Authentication is required.
